# 05_MODUL_AL_ADLHU_SODRI_NIWRAD_ANIMASI_KENDARAAN_KONTROL_SIMULASI

**Penanggung jawab:** Al Adlhu Sodri Niwrad

**Bagian tugas:** Animasi pergerakan kendaraan, kontrol simulasi, tombol Start, dan tombol Pause.

## Isi folder
- `source_full/` berisi file kode lengkap yang berhubungan dengan bagian ini.
- `cuplikan_kode_kunci.py` berisi potongan kode penting yang paling mudah dijelaskan di laporan atau video.
- File `ui/app.py` memang muncul di beberapa modul karena di dalam satu file itu terdapat beberapa fitur berbeda, seperti pemilihan titik, scroll, zoom, pencarian rute, dan animasi.

## File kode yang berkaitan
- `ui/app.py`
- `map/render/renderer.py`
- `map/kamera.py`

## Fokus penjelasan
Animasi pergerakan kendaraan, kontrol simulasi, tombol Start, dan tombol Pause.
