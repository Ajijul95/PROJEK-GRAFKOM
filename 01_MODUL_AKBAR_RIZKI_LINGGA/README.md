# 01_MODUL_AKBAR_RIZKI_LINGGA_STRUKTUR_PETA_JARINGAN_JALAN

**Penanggung jawab:** Akbar Rizki Lingga

**Bagian tugas:** Perancangan struktur peta dan pembentukan jaringan jalan secara dinamis.

## Isi folder
- `source_full/` berisi file kode lengkap yang berhubungan dengan bagian ini.
- `cuplikan_kode_kunci.py` berisi potongan kode penting yang paling mudah dijelaskan di laporan atau video.
- File `ui/app.py` memang muncul di beberapa modul karena di dalam satu file itu terdapat beberapa fitur berbeda, seperti pemilihan titik, scroll, zoom, pencarian rute, dan animasi.

## File kode yang berkaitan
- `map/grid_kota.py`
- `map/utils.py`
- `map/grid/grid_kota.py`
- `map/grid/roads.py`
- `map/grid/clip.py`
- `map/grid/vector.py`
- `map/grid/buildings.py`
- `map/grid/nature.py`
- `map/grid/__init__.py`

## Fokus penjelasan
Perancangan struktur peta dan pembentukan jaringan jalan secara dinamis.
